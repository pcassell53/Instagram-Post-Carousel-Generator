Instagram Post Carousel Generator

Paste Instagram post or reel URLs, generate a responsive carousel, preview it, and copy the finished HTML, CSS, and JavaScript.

How to use this generator

  1. Open the Instagram post or reel you want to include.
  2. Copy the full URL from the browser address bar, or use Instagram's share option to copy the link.
  3. Paste one Instagram URL per line into the field below.
  4. Click Generate Carousel Code, then copy the generated code.

Recommended URL format:

https://www.instagram.com/ford/reel/DZ7nrziALx6/

You can also enter IDs manually:

For a regular post, use p:POST_ID
For a reel, use reel:REEL_ID

The ID is the part after /p/ or /reel/. For example, in https://www.instagram.com/ford/reel/DZ7nrziALx6/, the reel ID is DZ7nrziALx6.
